## Development

Run the linter:

```
bb lint
```

Run the test suite:

```
bb test
```


Run the test suite in watch mode

```
bb test --watch
```

Run a specific test

```
bb test --focus sqlite4clj.functions-test/removing-functions
```

See [kaocha docs](https://cljdoc.org/d/lambdaisland/kaocha/) for more tips.
